New here? Six steps to a live, scheduled video pipeline.

Ship AI videos on autopilot — for free

Bring an LLM key. Push to GitHub. The engine handles research, scripting, voice, images, video assembly, SEO and publishing on schedule. No server, no DB.

🆓 Free except LLM tokens 🧠 Agentic planner ⬡ n8n-style graph builder 🎬 Video-native (ffmpeg) 🛡 Safety + budget breaker
1

Get a Gemini API key

Free tier is enough to start. Other LLMs (Claude / OpenAI) are pluggable.

Open Google AI Studio ↗
2

YouTube OAuth (5 min)

Enable YouTube Data API v3, create a Desktop OAuth client, then run locally:

python scripts/youtube_auth.py client_secret.json

Saves three values to paste as repo secrets.

3

Push to GitHub

Create a private repo, then:

git remote add origin https://github.com/YOU/REPO.git
git push -u origin main
4

Add secrets

Repo · Settings · Secrets and variables · Actions · New repository secret:

GEMINI_API_KEY
YOUTUBE_CLIENT_ID
YOUTUBE_CLIENT_SECRET
YOUTUBE_REFRESH_TOKEN
ADMIN_USERNAME   (optional — locks the editor)
ADMIN_PASSWORD   (optional — PBKDF2-hashed at deploy)
5

Enable the dashboard

Repo · Settings · Pages · Source: GitHub Actions. The dashboard you're viewing right now is automatically deployed.

6

Safe first run

Actions · video-workflow · Run workflow · set dry_run = true. Should turn green and produce a placeholder MP4. Then run again with dry_run = false — uploads as unlisted. Verify, then flip privacy to public in the workflow JSON.

What runs after that

Every 30 minutes a dispatcher checks config/schedules.yaml and runs any due workflow (default: three videos per day at 06:00 / 12:00 / 18:00 UTC). All metrics show up live on the dashboard. Edit workflows, providers, prompts, and schedules from the Studio & Visual Builder — changes commit back to the repo via your fine-grained token.
