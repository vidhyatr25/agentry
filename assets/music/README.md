# Background music

Drop royalty-free tracks here (for example `calm.mp3`) and reference them from a
workflow's `assemble_video` step via `params.music`. If the file is missing the
video is still produced without background music, so this is optional.

Use only music you are licensed to use (e.g. YouTube Audio Library, Pixabay,
Kevin MacLeod CC-BY with attribution in the description).
